Сервис для автоматического сбора, анализа и классификации отзывов о банках с сайта Banki.ru с использованием LLM-моделей.

## 📋 О проекте

Проект создан для автоматизации анализа клиентских отзывов о банках. Система позволяет:
- 📊 **Собирать отзывы** с Banki.ru с помощью парсера
- 🤖 **Анализировать контент** с использованием LLM-моделей через Ollama
- 🏷️ **Классифицировать отзывы** по категориям (сервис, продукт, сотрудник и др.)
- 📈 **Визуализировать статистику** через удобный веб-интерфейс
- 🔍 **Искать и фильтровать** отзывы по различным параметрам

## 🚀 Быстрый старт

### Предварительные требования

- **Docker** и **Docker Compose**
- **NVIDIA GPU** с установленными драйверами CUDA (рекомендуется)


### Проверка поддержки GPU

```bash
# Проверьте, что CUDA доступна
docker run --rm --gpus all nvidia/cuda:12.2.0-base-ubuntu22.04 nvidia-smi
```

### 🛠️ Установка и запуск

1. **Клонирование и запуск**
   ```bash
   # Склонируйте репозиторий
   
   # Соберите и запустите контейнеры
   docker compose build
   docker compose up -d
   ```

2. **Загрузка ML-моделей**
   
   Выберите модель в зависимости от ваших потребностей:

   ```bash
   # Для быстрых тестов (меньшая точность)
   docker exec -it gemma-server ollama pull gemma3:1b
   
   # Для качественного анализа (рекомендуется)
   docker exec -it gemma-server ollama pull gemma3:12b
   ```

3. **Доступ к сервису**
   
   Откройте веб-браузер и перейдите по адресу:
   ```
   http://localhost:8501
   ```

## ⚠️ Важные замечания

### Парсинг данных
- ⏱️ **Используйте задержку 3-4 секунды** между запросами к Banki.ru
- 🛡️ Это необходимо для избежания ошибки 403 и блокировки IP
- 🔄 Настройка задержки доступна в интерфейсе парсера

### Аппаратные требования
- Для работы с моделью `gemma3:12b` рекомендуется **32+ ГБ ОЗУ**
- При использовании GPU проверьте доступность CUDA через команду выше
- Для CPU-режима выберите модель `gemma3:1b`

## 🏗️ Архитектура

Компоненты системы

## 🐛 Устранение неполадок

### Проблема: Ошибка 403 при парсинге
**Решение:** Увеличьте задержку между запросами до 4-5 секунд в настройках парсера.

### Проблема: Медленная работа модели
**Решение:**
1. Проверьте использование GPU: `nvidia-smi`
2. Рассмотрите переход на модель `gemma3:1b`
3. Увеличьте объем оперативной памяти

### Проблема: Контейнеры не запускаются
**Решение:**
```bash
# Просмотр логов
docker compose logs

# Пересборка образов
docker compose down
docker compose build --no-cache
docker compose up -d
```

**Примечание:** Используйте сервис ответственно, соблюдая правила Banki.ru и законодательство РФ о защите данных.
