# Бизнес-анализ проекта: Платформа для автоматизации работы с отзывами

---
## **Введение**
На лекции с Марком обсуждали подход "от меньшего к большему" в реализации функционала. Этот документ описывает бизнес-анализ проекта, ориентируясь на реалистичные сроки курса. В конце документа приведено видение "идеальной" реализации проекта.

---

## **1. Бизнес-анализ (Business Understanding)**

### **Цели проекта**
- **Цель:** Создание платформы для автоматизации работы с отзывами: саммаризация текста, выделение ключевых позитивных аспектов и проблем клиентского сервиса и продукта.
- **Бизнес-цель:** Определение ключевых проблем в клиентском пути, оптимизация модели обслуживания клиентов.
- **ML-задача:** Саммаризация текстов отзывов, анализ тональности отзывов.

### **Заказчик и пользователи**
- **Заказчик:** Подразделения Run и Change банка, ответственные за ипотечное кредитование.
- **Пользователи:** Сотрудники данных подразделений.
- **Контакты:** Экспертные консультации с сотрудниками подразделений при необходимости.

---

## **2. Существующие решения**

### **Внутренние решения**
- В банке существует платформа для работы с отзывами. Необходим инструмент для более углубленной работы, учитывающий специфику бизнес-подразделения.

### **Рыночные решения (бенчмарки)**
| Решение                | Особенности                                                                                     | Тарификация          |
|------------------------|-------------------------------------------------------------------------------------------------|----------------------|
| **rocketdata.ru**      | Удобный личный кабинет, визуализация, выделение тем, конкурентный анализ, саммаризация.         | По запросу           |
| **pntr.io**            | Личный кабинет, анализ филиалов, саммаризация, автоответы на отзывы, скорость инференса.       | По запросу           |
| **bigchallenges.ru**   | Учебный проект (Газпромбанк), поиск фейковых отзывов, устаревшая визуализация.                  | Проект закрыт       |

### **Проблемы рыночных решений**
1. Риски обработки персональных данных.
2. Ограниченные бюджеты подразделений.
3. Длительное внедрение внешних решений.
4. Необходимость дообучения моделей под специфику продукта.

## **3. Текущая ситуация (Assessing current solution)**

### **Техническое обеспечение**
- **Личные мощности:** 32 ГБ ОЗУ, видеокарта 3070ti 8 ГБ.
- **Рыночные решения:** Аренда мощностей (например, Selectel: 128 ГБ ОЗУ, видеокарта 4090).
- **Оценка:** Личного оборудования достаточно для MVP. Инференс отзывов за неделю на CPU некритичен для заказчика.

### **Данные**
- **Идеальный датасет:** Отзывы с Banki.ru по продукту (достаточно атрибутов, пятибалльная система оценки).
- **Способы получения:**
  1. Парсинг данных.
  2. Доступ к платформе Banki.ru (ожидается согласование).

### **Эксперты**
- Доступны эксперты из подразделений Run и Change для консультаций и обратной связи.

### **Риски**
1. Комплексность задачи и самостоятельная реализация.
2. Недооценка вычислительных мощностей.
3. Отказ в доступе к официальной платформе.
4. Длительная работа парсера.
5. Поверхностные выводы модели.

## **4. Решаемые задачи с точки зрения аналитики (Data Mining goals)**

### **Метрики**
| Задача                  | Метрики                                                                 |
|-------------------------|-------------------------------------------------------------------------|
| **Анализ тональности**  | F1 (3 класса: позитивный, негативный, нейтральный). Дисбаланс классов. |
| **Саммаризация**        | BLEU, ROUGE, METEOR, BERTScore (если хватит мощности), экспертная оценка. |

### **Критерий успешности**
- F1: 0.7–0.8
- METEOR: ≥ 0.35–0.40
- BERTScore (F1): ≥ 0.85
- BLEU: 0.20–0.29
- ROUGE-1: 0.40–0.50
- ROUGE-2: 0.20–0.30
- Экспертная оценка заказчиками на выборке.

## **6. Идеальное видение сервиса**

Идеальная реализация должна представлять из себя web-сервис со следующим функционалом.
1. Самммаризация отзывов с бинарной классификацией на тематику продаж и постпродажного обслуживания.
2. В рамках выделенных тематик классификация основных тем обращений клиентов.
3. Выделение основных тем обращений в рамках указанных временных периодов (неделя, месяц, квартал, год).
4. Реализация функционала конкурентного анализа на временных отрезках.
5. Построение модели предсказания тренда оценки банков по услуге.
6. Внедрение гео-аналитики. Анализ проблематики в рамках федеральных округов, городов.
